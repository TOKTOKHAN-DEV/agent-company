# 04 — 심사 체크리스트

토스 미니앱은 **심사를 통과해야 나갑니다.** 검수는 영업일 3일까지, 카테고리에 따라 7일 이상
걸릴 수 있습니다. 반려되면 그만큼 다시 기다립니다.

> **심사 항목은 계속 갱신됩니다.** 제출 전에 원문을 다시 확인하세요.
> 비게임: https://developers-apps-in-toss.toss.im/checklist/app-nongame.md
> 게임: https://developers-apps-in-toss.toss.im/checklist/app-game.md

---

## 기계가 잡는 것 / 사람이 봐야 하는 것

`pnpm preflight` 는 **기계로 판정 가능한 것만** 봅니다. 통과했다고 심사를 통과하는 게 아닙니다.

| preflight 가 잡음 | 사람이 봐야 함 |
| --- | --- |
| `eval` · `new Function` | 인터랙션이 2초 안에 반응하는가 |
| `ws://` (wss 만 허용) | 뒤로가기 버튼이 두 개 동시에 보이는가 |
| `intoss-private://` | 결제·광고 중 배경음이 멈추는가 |
| `prefers-color-scheme: dark` | 광고가 미리 로드되는가 |
| TDS 미사용 | 배너가 스크롤 화면에만 뜨는가 |
| `user-scalable=no` 누락 | 비속어·과도한 유행어 |
| 수용 기준 없는 명세 | 권한 거부 시 기능이 도는가 |
| 번들 100MB 초과 | 실기기 레이아웃 |
| 정적 산출물 여부 | 재시작 후 데이터 유지 |
| appName · 개인정보처리방침 | |

## 접근과 기능

- [ ] 미니앱이 정상적으로 열린다
- [ ] 홍보한 인앱 서비스가 미니앱에서 동일하게 동작한다
- [ ] 등록한 스킴으로 진입이 된다
- [ ] 스킴 진입 후 뒤로가기가 정상 동작한다

## 내비게이션 바

- [ ] 토스 비게임 내비게이션 바를 쓴다
- [ ] 모든 화면에서 뒤로가기(`<`)가 동작한다
- [ ] 중앙에 브랜드 로고와 한글 미니앱 이름이 보인다
- [ ] 홈 버튼이 동작한다 (선택)
- [ ] 우측 기능 버튼은 최대 1개 (선택)
- [ ] **뒤로가기 버튼이 두 개 동시에 보이지 않는다**
- [ ] 더보기(⋯)에 신고·공유 같은 토스 표준 기능이 있다
- [ ] 닫기와 뒤로가기가 분명하고 동작한다
- [ ] **첫 화면에서 뒤로가기를 누르면 미니앱이 닫힌다**
- [ ] 탭바를 쓴다면 토스 앱과 같은 플로팅 형식이다

## 사용자 식별

- [ ] 사용자 식별값이 저장되고 미니앱이 정상 시작된다
- [ ] 사용자 히스토리가 유지된다
- [ ] 앱을 재시작해도 데이터가 남는다

## 보안과 안정성

- [ ] **외부 코드 실행(`eval` 등)이 없다** — preflight
- [ ] 브라우저 히스토리를 조작하는 리다이렉트가 없다
- [ ] **CSR 또는 SSG 만 쓴다 (SSR 금지)** — preflight
- [ ] **소켓은 `wss://` 만 쓴다** — preflight

## 사용 동작

- [ ] **확대 제스처가 꺼져 있다** (지도 등 본질적인 경우 제외) — preflight
- [ ] **라이트 모드만 지원한다** — preflight
- [ ] 모든 UI 컴포넌트가 의도대로 동작한다
- [ ] 인터랙션이 2초 안에 반응한다
- [ ] 재시작 후에도 데이터가 유지된다
- [ ] 외부 링크가 정상적으로 열린다
- [ ] **공유는 `intoss://` 를 쓴다 (`intoss-private://` 금지)** — preflight
- [ ] 비속어·은어·과도한 유행어가 없다
- [ ] 사용자 확인이 필요한 곳에 TDS 모달을 쓴다
- [ ] 불법·선정적 콘텐츠가 없다
- [ ] (RN) 권한 요청 전에 사용자 동의를 받는다
- [ ] **권한이 거부돼도 기능이 동작한다**
- [ ] 비정상적인 네트워크·메모리 사용이 없다

## UX

- [ ] **진입하자마자 바텀시트가 뜨지 않는다**
- [ ] 바텀시트가 강제로 화면을 이동시키지 않는다
- [ ] 모든 화면에 빠져나갈 방법이 분명하다
- [ ] CTA 버튼이 무슨 일이 일어날지 드러낸다
- [ ] 자사 서비스로 보내거나 앱 설치를 유도하지 않는다
- [ ] 인트로·로딩·컷신·팝업 같은 임시 화면에 인앱 광고를 넣지 않는다

## 토스 로그인 (쓴다면)

- [ ] 인트로 화면에 서비스 설명이 있다
- [ ] 약관 화면 URL 이 정상 표시된다
- [ ] 로그인 요청을 닫으면 미니앱이 종료된다
- [ ] 연결 해제 후 재진입 시 다시 로그인을 요구한다
- [ ] 연결 해제 시 사용자 데이터가 삭제된다
- [ ] **다른 로그인 수단을 만들지 않았다**

## 인앱 결제 (쓴다면)

- [ ] 결제 중 배경음이 멈춘다
- [ ] 주문 금액과 결제창 금액이 일치한다
- [ ] 결제가 정상 처리된다 (구글 테스트 환경 포함)
- [ ] 복귀 시 결과가 반영된다
- [ ] 취소하면 주문 화면으로 돌아온다
- [ ] 실패 사유가 전달된다
- [ ] 환불이 정상 처리된다
- [ ] 구매 내역을 볼 수 있다
- [ ] 기기를 바꿔도 데이터가 유지된다

## 토스페이 (쓴다면)

- [ ] 결제 중 배경음이 멈춘다
- [ ] 금액이 결제창과 일치한다
- [ ] 실패 메시지가 원인을 알려준다
- [ ] 결제 전 취소 시 이전 화면으로 돌아온다
- [ ] **토스페이가 유일한 결제 수단이다**
- [ ] 결제 중 취소 시 주문 화면으로 돌아온다

## 인앱 광고 (쓴다면)

- [ ] 광고 재생 중 배경음이 멈춘다
- [ ] 광고가 예기치 않게 뜨지 않는다
- [ ] 광고가 끊김 없이 로드·재생된다
- [ ] **미리 로드한다 (실시간 로딩 금지)**
- [ ] 광고 종료 후 정상 복귀한다
- [ ] 광고 후 음악이 다시 재생된다
- [ ] 리워드 광고가 보상을 정상 지급한다
- [ ] 배너가 상·중·하 적절한 위치에 있다
- [ ] **배너는 스크롤 가능한 화면에만 표시된다**

## 친구 초대 보상 (쓴다면)

- [ ] 보상 화면이 정상 표시된다
- [ ] 닫은 뒤 미니앱으로 정상 복귀한다
- [ ] 초대 완료 시 보상이 지급된다

## 반려됐을 때

1. `release-manager` 가 `review_get_feedback` 으로 사유를 가져온다
2. `release/<버전>.md` 에 **원문 그대로** 기록한다
3. `spec-writer` 가 그 사유를 해당 명세의 **수용 기준으로 추가**한다

같은 이유로 두 번 반려되지 않게 하는 방법은 수용 기준에 넣는 것뿐입니다. 사람의 기억에
맡기면 다음 릴리즈에서 또 걸립니다.
