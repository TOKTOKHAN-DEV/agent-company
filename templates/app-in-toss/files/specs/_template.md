## 배경

왜 만드는가. 없으면 무엇이 불편한가. 대안을 검토했다면 왜 버렸는가.

## 화면

| 경로 | 이름 | 역할 |
| --- | --- | --- |
| `/` | 홈 | 진입점 |
| `/<path>` | <이름> | <한 줄> |

각 화면에 대해:

- **진입** — 어디서 어떻게 들어오는가
- **이탈** — 어떻게 빠져나가는가 (모든 화면에 이탈 경로가 있어야 합니다)
- **빈 상태 / 로딩 / 실패** — 각각 무엇을 보여주는가

## 수용 기준

체크 가능한 문장으로 씁니다. "잘 동작한다" 는 수용 기준이 아닙니다.

- [ ] 첫 화면에서 뒤로가기를 누르면 미니앱이 닫힌다
- [ ] 모든 인터랙션이 2초 안에 반응한다
- [ ] 앱을 재시작해도 <무엇>이 유지된다
- [ ] 권한을 거부해도 <무엇>은 동작한다
- [ ] 네트워크가 끊기면 <어떤> 안내가 뜬다

## 심사 관련

이 기능이 건드리는 심사 항목을 적습니다. 전체 목록은 `wiki/04-review-checklist.md`.

- [ ] 진입하자마자 바텀시트를 띄우지 않는다
- [ ] 확대 제스처가 꺼져 있다
- [ ] 라이트 모드만 쓴다
- [ ] (결제가 있다면) 결제 중 배경음이 멈춘다
- [ ] (광고가 있다면) 광고를 미리 로드한다
