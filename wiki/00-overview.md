# 00 — 프로젝트 개요

## 한 줄 정의

**Orca AI Company**는 Orca 사용자가 IT 프로젝트를 AI 에이전트 팀으로 굴릴 수 있도록 만든 모노레포 템플릿입니다.
레퍼런스 구현으로 "AI가 운영하는 블로그"가 들어 있습니다.

## 해결하려는 문제

AI에게 프로젝트를 맡길 때 반복해서 무너지는 두 가지:

1. **컨텍스트 소실** — 세션이 끝나거나 담당자가 바뀌면 AI는 지난 결정을 모른다. 같은 논의를 반복하고, 이미
   폐기된 방식으로 되돌아간다.
2. **품질 관리 부재** — 검수 게이트가 없으면 AI 결과물이 그대로 프로덕션에 나간다.

## 해결 방식

| 문제 | 구조적 해결책 |
| --- | --- |
| 컨텍스트 소실 | `CLAUDE.md` + `AGENTS.md` + `wiki/` + `wiki/memory/`를 SessionStart 훅으로 자동 로드 |
| 품질 관리 | `auditPost()` 결정적 검사 + admin 검수 화면 + 사람만 누를 수 있는 발행 버튼 |
| 역할 혼재 | `agents/` 페르소나 정의 + 모델 지정 + 멀티 터미널 병렬 실행 |
| 이미지 신뢰성 | Codex `imagegen` 단일 경로 + `cover.source` 출처 기록 |

## 구성 요소

```
apps/web      공개 블로그 (Next.js 16, App Router)
apps/admin    콘텐츠 · SEO/GEO · 검수 대시보드 (Next.js 16)
packages/content  콘텐츠 스키마 · 파일 IO · 감사 · JSON-LD (단일 진실 공급원)
content/posts     마크다운 글 (DB 없음)
agents/       독립 실행 에이전트 (AGENT.md + skills/) + 런타임·모델 매핑
wiki/         프로젝트 지식 + 장/단기 메모리
.claude/      훅 · 슬래시 커맨드
scripts/      결정적 셸 스크립트 (setup, 의존성 검사, imagegen)
```

## 핵심 불변 규칙

이 규칙들은 코드보다 오래 갑니다. 바꾸려면 ADR을 먼저 쓰세요.

1. **이미지 생성은 Codex `imagegen` 전용.** Claude의 이미지 합성은 금지.
2. **발행은 사람만.** 에이전트는 `in_review`까지만 올린다.
3. **콘텐츠의 진실은 파일.** DB나 외부 CMS를 도입하지 않는다.
4. **검수는 결정적으로.** 게이트 판단에 모델 추론을 넣지 않는다.
5. **세션 시작 시 컨텍스트 로드는 자동.** 사람이 기억해서 시키지 않는다.

## 레퍼런스 도메인: 블로그

템플릿을 이해하기 쉽도록 블로그 도메인으로 구현되어 있습니다. 다른 도메인(커머스, 대시보드, 문서 사이트)으로
바꿀 때는 `packages/content`의 스키마와 `agents/` 페르소나를 교체하고, 나머지 뼈대(훅 · 메모리 · 검수 게이트)는
그대로 씁니다.
